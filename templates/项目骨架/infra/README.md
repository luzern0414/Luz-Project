# 数据库迁移说明

迁移源码放在 `infra/migrations/`。表结构由同一条版本迁移链维护。开发和测试所需的合成数据可放 `data/seeds/`，测试专用样本随测试存放。业务数据、备份和本地数据库文件放在项目约定的受控位置。

| 交接事项 | 示例 | 本项目 |
|---|---|---|
| 数据库与工具 | PostgreSQL 与 Alembic | 〔填写实际数据库和迁移工具〕 |
| 迁移版本 | `001_create_members` 建立会员表 | 〔填写上一版本与目标版本〕 |
| 执行入口 | 从已配置的项目环境执行 `alembic upgrade head` | 〔填写实际命令和配置位置〕 |
| 验证 | 从空库及上一版本各迁移一次，核对表结构与业务用例 | 〔填写环境和验证记录位置〕 |
| 发布与恢复 | 在发布前记录备份及回退依据，由运维核对恢复结果 | 〔填写实际发布入口、责任人和恢复记录〕 |

已发布的版本通过新增迁移处理后续变化。表结构更新随对应代码一起评审。字段、索引、并发迁移与线上恢复按项目采用的 Luz-Dev 技术底座和运维流程执行。
