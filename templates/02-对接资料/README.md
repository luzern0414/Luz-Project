# 02-对接资料模板

商业项目按[项目路线](../../references/commercial-project.md)使用 01 至 06。01 与 02 首次一批生成，03 至 06 在交互 Demo 通过后定稿；后续文档编号取本项目矩阵。下表编号用来定位母版。

模板按常见对接流程排列。先明确需求和范围，再确认规则、计划与商务事项，随后处理变更、试用和验收。单独归档已有资料时，按实际采用顺序和已有外发记录编号，文件名用 `NN-文种.扩展名`。命名示例见[对接资料归档](../../references/project-structure.md#02-对接资料)。

| 模板编号 | 文档 | 用途 | 模板与示例 |
|---|---|---|---|
| 01 | `需求说明` | 确认项目目标、业务范围、具体要求和验收标准 | [Word](./01-需求说明.docx) |
| 02 | `系统方案` | 说明建设内容、阶段成果与双方职责 | [Word](./02-系统方案.docx) |
| 03 | `架构图` | 展示使用端、业务模块、数据与外部服务的关系 | [可编辑图稿](./03-架构图.pptx) · [PDF 示例](./03-架构图.pdf) |
| 04 | `功能需求清单` | 按使用端和功能模块确认功能范围与验收标准 | [Excel](./04-功能需求清单.xlsx) |
| 05 | `业务规则确认表` | 确认拟定规则和可选功能，同表回填所需资料 | [Excel](./05-业务规则确认表.xlsx) |
| 06 | `项目实施计划表` | 明确实施阶段、时间、责任方和确认节点 | [Excel](./06-项目实施计划表.xlsx) |
| 07 | `项目报价表` | 按需列明经人工确认的报价项目、计价口径、有效期和金额 | [Excel](./07-项目报价表.xlsx) |
| 08 | `合作协议书` | 确认合作范围、交付、结算和签署事项 | [Word](./08-合作协议书.docx) |
| 09 | `需求变更确认表` | 已确认的需求发生新增或调整时，记录影响与实施安排 | [Excel](./09-需求变更确认表.xlsx) |
| 10 | `使用指南` | 在试用和交接时指导各角色操作及处理常见问题 | [Word](./10-使用指南.docx) |
| 11 | `项目验收清单` | 按功能记录验收场景、通过标准、凭据和结论 | [Excel](./11-项目验收清单.xlsx) |
| 12 | `产品介绍` | 以交付产品的功能和真实界面制作宣传 PDF | [可编辑母版](./12-产品介绍.pptx) · [宣传 PDF 示例](./12-产品介绍.pdf) |

设备选型、上线交接、运行维护等其他材料按需采用。架构图可作为系统方案的附件。内容依据见[客户文档](../../references/client-documents.md)。

- 用已确认的项目事实替换示例。Word 定稿后更新目录和页码，再导出 PDF。
- 功能需求清单按「使用端 → 功能模块 → 使用角色」分组。同一上级内相邻的同名标签纵向合并，功能编号和范围逐行记录。
- 项目报价表的数量和单价由人员提供，金额与合计自动计算。增加报价项时在明细区内插入行并复制相邻金额公式，核对合计覆盖范围。
- 合作协议书沿用需求说明和系统方案的字体、字号、正文行距及版心。将 `〔 〕` 中的填写项换成双方确认的信息，核对金额大小写、付款期限、验收期限、违约金率和附件版本。签署前向甲方提示加粗条款，按其要求说明。
- Excel 采用浅蓝灰标题与表头。报价手填项带浅蓝底，金额公式与合计带浅绿底。功能范围与接收状态保留文字，选择后会显示对应底色。
- 项目验收清单按功能归组，逐个场景填写实际结论和凭据。业务规则确认表的资料页按分类和子类归组，「使用场景」说明在什么业务环节由谁使用资料，以及用于什么操作。回填经授权的信息或文件链接，账号凭据通过约定渠道交接。
