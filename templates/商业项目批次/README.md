## 库存口径

| 业务动作 | 业务结果 | 库存结果 |
|---|---|---|
| 到货收货 | 单据转待上架 | 存放库位余额保持原值 |
| 入库上架 | 入库单完成 | 目标库位账面和可用量按实收量增加 |
| 出库分配 | 生成拣货任务 | 按计划量增加预占、减少可用 |
| 拣货复核 | 通过后转待发运 | 保留整笔计划预占 |
| 实际发运 | 生成出库流水和回传事件 | 按实拣量扣账面，释放整笔计划预占 |
| 库内移库 | 形成一张移库单、两笔流水 | 源库位减少，目标库位等量增加 |
| 差异盘点 | 主管复核后生成调整流水 | 按核准差额调整账面 |

入库、出库共用单头和商品行结构。单头记录仓库、往来方和单号，商品行独立办理，各行流水可回查原业务单号、行号。多行共用同一库位批次时，按剩余可用量累计预占。

可用量等于账面量减预占量。计划十件、实拣八件时，发运扣账面八件，释放预占十件，可用回升两件。回传超时后复用原事件键重试。
