# 03-开发资料模板

商业项目的 01 至 04 同批评审，05 是可操作的交互原型；后续编号由项目矩阵分配。下表编号保留给按需归档的模板，业务功能编号贯穿两种模式。见[项目路线](../../references/commercial-project.md)。

模板按设计、实现、验证、上线和运维顺序排列。表内编号用于定位母版。单独整理档案时，文件名按实际采用的文种和顺序编排。项目名称和编号写在项目目录与正文。通用规则见[编号与归档](../../references/project-structure.md#编号与归档)。编号模板共用示例健身运营系统的功能编号。

| 模板编号 | 文档 | 记录内容 |
|---|---|---|
| 01 | [功能说明](./01-功能说明.md) | 角色、入口、业务流程、规则与异常 |
| 02 | [技术方案](./02-技术方案.md) | 模块分工、数据关系、环境与技术决策 |
| 按需 | [Agent 数据底座](./Agent数据底座.html) | 项目库、业务表、字段、关联和指标计算路径 |
| 03 | [前端开发说明](./03-前端开发说明.md) | 页面、状态、接口映射与界面依据 |
| 04 | [后端开发说明](./04-后端开发说明.md) | 接口、权限、数据处理和一致性 |
| 05 | [开发记录](./05-开发记录.md) | 本轮版本、变更、验证与遗留项 |
| 06 | [测试方案](./06-测试方案.md) | 测试范围、用例、结果与复测依据 |
| 07 | [上线方案](./07-上线方案.md) | 发布顺序、验证节点、停止和回退条件 |
| 08 | [运维手册](./08-运维手册.md) | 接手范围、巡检、备份恢复和报障 |

功能编号贯穿实现、测试与客户验收。项目已维护的接口、设计稿和运行手册可直接引用。各阶段生成 HTML 评审页的输入要求见[开发文档标准](../../references/dev-documents.md)。

## Agent 数据底座

有问数或业务分析的项目在技术方案后按顺序归档。HTML 母版内置虚构的商业运营样例，`foundation-data` 数据块可作为填写示例。以一个项目库组织业务表，填写实际表名、每行记录代表的对象、字段含义、单位和来源。关联标明两侧的表和字段，问数路径写明所需字段、计算公式和适用口径。

生成正式文件时，选择共享模板登记项 `data-foundation-html` 绑定输出路径，再用 [Project 数据底座生成器](../../scripts/make_data_foundation.py) 的 `--data` 传入项目数据。生成的单个 HTML 可离线打开，缺少三维渲染能力时可使用平面关系图。
